# LiH 零温能量曲线复现实验设计

日期：2026-05-05

## 1. 目标与边界

本项目复现论文 `Zero and Finite Temperature Quantum Simulations Powered by Quantum Magic` 中 LiH 零温能量曲线的核心成果：生成类似本地论文图像 `arXiv-2308.11616v2/figs/ener.pdf` 中的 `E - E0` 随 LiH 键长变化的曲线，并展示 Clifford + `kRz` ansatz 随 `k` 增大而改善精度的趋势。

复现目标是“严格实现本地论文中描述的算法结构，近似复现图像趋势”。本项目不宣称逐点严格复现论文原始数值，因为本地论文文件缺少以下关键信息：精确键长网格、基组、active space、冻结轨道、tapering 方案、SBRG 初始化细节、Clifford 层数 `L`、随机种子、最终电路和优化参数。

`ener.pdf` 只作为辅助验证目标，用于比较曲线趋势、量级和视觉形态，而不是作为必须逐点匹配的 ground truth。本轮范围只包含 LiH 零温曲线，不扩展到 H2O、有限温图、Rydberg 模拟图或其他论文图像。

## 2. 总体结构

实现将组织为一个本地可复现实验项目，包含五个模块。

第一，论文图像辅助验证模块读取或 digitize 本地 `ener.pdf`，提取可用于趋势比较的曲线信息。该数据只用于辅助验证和报告说明，不参与算法优化目标。

第二，LiH Hamiltonian 生成与缓存模块在明确记录假设的前提下，为每个 LiH 键长生成或加载 8-qubit Pauli Hamiltonian。每个 Hamiltonian、键长、映射方式、依赖版本和生成参数都要保存到缓存中，避免后续运行时隐含改变实验对象。

第三，Clifford + `kRz` ansatz 模块实现论文描述的 brickwork Clifford 结构和可变数量的单量子比特 `Rz` 门。默认支持多个 `k`，例如 `k = 0, 1, 2, 3`；`k = 0` 表示纯 Clifford 基线。

第四，优化模块实现两层优化：连续角度 `Theta` 使用多初值连续优化，离散 Clifford 选择与 `Rz` 位置使用随机化 greedy search。每个键长和每个 `k` 都保存随机种子、best energy、离散参数、连续角度和优化 trace。

第五，绘图与报告模块输出 `E - E0` vs bond length 图像，对比 HF 基线和不同 `k` 曲线，并在图题或说明中明确标注这是“算法结构复现 + 图像辅助验证”，不是论文隐藏数值的严格复现。

## 3. 数据、算法与验证细节

数据分为两类。第一类是实验 Hamiltonian 数据，由本地代码在明确假设下生成并缓存；第二类是论文图像辅助数据，由 `ener.pdf` 提取，用于后验趋势比较。若 OpenFermion、PySCF 或相关量子化学依赖在当前环境中不可用，项目仍应保留可安装的 Python 项目结构、Hamiltonian 缓存接口和降级说明，清楚说明哪一步因环境依赖未能执行。

算法以 8-qubit LiH Hamiltonian 为目标。对每个键长，先通过精确对角化得到参考基态能量 `E0`。然后对每个 `k` 构造 Clifford + `kRz` ansatz，优化得到能量 `E`，最终绘制 `E - E0`。`k = 0` 是纯 Clifford；`k > 0` 增加 `k` 个单量子比特 `Rz` 门。离散 Clifford 参数和 `Rz` 位置使用随机化 greedy search；`Rz` 连续角度使用多初值连续优化，并限制在论文描述的周期范围内。

验证标准包括四项。第一，同一随机种子下结果可复现。第二，每次实验保存 Hamiltonian、种子、优化 trace、最终参数和最终能量。第三，结果趋势应合理：通常较大的 `k` 应降低或至少不显著恶化 `E - E0`，并在中间键长区域体现更明显的困难度。第四，最终报告要与 `ener.pdf` 做辅助比较，并解释差异来自本地论文缺失的隐藏参数与实现假设。

## 4. 非目标

本项目不实现 H2O 曲线、有限温 Gibbs state 复现、Rydberg analog 模拟、完整 SBRG 算法、论文作者原始优化参数恢复或逐点拟合 `ener.pdf`。如果后续需要这些内容，应作为单独设计和实现周期处理。

## 5. 交付物

预期交付物包括：本地 Python 项目结构、Hamiltonian 生成/缓存代码、Clifford + `kRz` ansatz 和优化代码、运行脚本、结果缓存、复现图像、辅助验证图像或报告，以及一份说明复现边界和差异来源的简短 Markdown 报告。

## 6. 风险与缓解

主要风险是本地论文文件缺少原始数值与 Hamiltonian 生成细节，导致数值曲线无法与论文图逐点一致。缓解方式是在代码和报告中显式记录所有假设，并把 `ener.pdf` 作为非权威辅助验证。

第二个风险是完整量子化学依赖可能无法在当前环境中安装或运行。缓解方式是将 Hamiltonian 生成和优化解耦，通过缓存接口保存已生成 Hamiltonian；如果生成失败，报告应明确指出依赖限制，并保留后续补充缓存数据后继续运行的路径。

第三个风险是 randomized greedy search 计算量较大。缓解方式是先提供小规模默认配置用于快速验证，再允许通过配置提高 `n_init`、`n_iter`、键长数量和 `k` 范围。
